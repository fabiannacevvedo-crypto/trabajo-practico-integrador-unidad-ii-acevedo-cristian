##  Descripción del Proyecto

Este proyecto consiste en el desarrollo de un sitio web institucional para el Instituto Politécnico Formosa (IPF).
El objetivo es aplicar los conocimientos adquiridos en HTML, CSS y Bootstrap para crear una página web responsiva, organizada y funcional.

El sitio cuenta con varias paginas:

* Inicio
* Institucional
* Carreras
* Contacto

Además, se implementó el uso de Git y GitHub para el control de versiones, trabajando con ramas y merges.

##  Tecnologías Utilizadas

* HTML
* CSS
* Bootstrap 
* Git
* GitHub
